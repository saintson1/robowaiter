# RoboWaiter

## Общий принцип работы

Сначала оператор вручную проводит робота по помещению, а система по данным камер и одометрии строит глобальную карту. На готовой карте задаются начальное положение робота и точки остановок, между которыми планируется маршрут. Во время движения робот следует этому маршруту и объезжает появившиеся препятствия.


## Архитектура

```text
RealSense A/B
    │ RGB/IR + depth
    ▼
dual_odometry
    │ /dual_odometry/odom, TF odom → base_link
    ├──────────────► global_mapper ──► global_map.pgm/yaml
    │
    ▼
navigation_node ◄── saved_map_server ◄── global_map.yaml
    │ /nav_cmd_vel
    ▼
safety_node
    │ /cmd_vel
    ▼
нода колёс
```

## Пакеты

- `mila_local_mapper` — запускает камеры и вычисляет визуальную одометрию.
- `mila_global_mapper` — строит OccupancyGrid и сохраняет глобальную PGM/YAML-карту.
- `mila_planner` — загружает карту, строит путь и формирует безопасную команду скорости.

Локальная карта препятствий пока не реализована. Поэтому физический выход навигации по умолчанию заблокирован.
