# Planner

Пакет строит глобальный маршрут по сохранённой карте и формирует команды для автомобильной кинематики.

## Ноды

### `mila_saved_map_server`

Загружает `global_map.yaml` и PGM-изображение, преобразует их в `nav_msgs/OccupancyGrid` и публикует `/map`.

### `mila_navigation`

Привязывает `map` к текущему `odom`, принимает `/goal_pose`, строит forward-only путь через Hybrid A* и публикует:

- `/navigation/global_plan`;
- `/nav_cmd_vel`.

Ограничения: движение только вперёд, минимальный радиус `0.70 м`, ориентация цели не учитывается.

### `mila_safety_supervisor`

Проверяет свежесть команды и одометрии, ограничивает скорость, ускорение и кривизну. Это единственная нода, публикующая `/cmd_vel`.

При ошибке или устаревших данных публикует нулевую скорость. До появления локальной карты движение по умолчанию отключено.

## Запуск

```bash
MILA_INITIAL_X=0.0 MILA_INITIAL_Y=0.0 MILA_INITIAL_YAW=0.0 \
MILA_GOAL_X=1.0 MILA_GOAL_Y=1.0 \
bash run_navigation.sh
```
